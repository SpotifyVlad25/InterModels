# КОМПОЗИТАРИЙ

КОМПОЗИТАРИЙ — отдельная Telegram forum topic, в которой хранится по одному обновляемому альбому композиток на модель.

## Подключение

1. Создать отдельную тему форума с названием «КОМПОЗИТАРИЙ».
2. Внутри этой темы отправить боту секретарю фразу `подключить композитарий` (или команду `/compositarium_setup`).
3. У бота должны быть права отправлять и удалять собственные сообщения в группе.

## Генерация

В теме «КОМПОЗИТКИ» выполнить `/composite_setup` или отправить `подключить композитки`, чтобы показать кнопки:

- «➕ Композитка» — стандартное создание одного выбранного варианта.
- «🧩 СЕТ» — запрос полного сета для одной модели.

После нажатия «СЕТ» отправить полное имя и фамилию одной модели. Бот проверяет наличие обоих фотокомплектов (Basic и Fashion), затем последовательно создаёт четыре варианта: русский Basic, русский Fashion, English Basic, English Fashion. Сет не использует очередь пакетной генерации. Альбом в КОМПОЗИТАРИИ обновляется только после успешного создания всех четырёх вариантов; если генерация неполная, прежний альбом остаётся нетронутым.

Обычная одиночная генерация также отражается в КОМПОЗИТАРИИ. В рабочей теме «КОМПОЗИТКИ» варианты остаются независимыми: новая публикация заменяет только тот же стиль и язык.

## Альбом

Для каждой модели поддерживается одна публикация. Первая композитка отображается отдельной фотографией с подписью модели; начиная со второй Telegram публикует варианты единым media group. При обновлении альбом отправляется заново, затем удаляется прежняя публикация. Существующие варианты без сохранённого Telegram file ID восстанавливаются из сохранённых исходных фотографий и снимка анкеты.
