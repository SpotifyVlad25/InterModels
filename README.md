# InterModels

Закрытая система модельного агентства на Cloudflare Workers + D1 с Telegram-ботами.

## Production-инфраструктура

В production уже настроены:
- Cloudflare Worker `intermodels`;
- Cloudflare D1 `intermodels-db`;
- webhook-маршруты Model и Director;
- автоматический деплой через GitHub Actions;
- Telegram ID владельца и директора;
- регистрация по ФИО или собственному контакту, поиск анкеты и ручное решение директора.

Директор и заместитель директора имеют одинаковые полные права. В Mini App действия выполняются под личным Telegram-профилем каждого. Уведомления директору содержат кнопки управления; заместитель директора получает уведомления без кнопок для контроля и выполняет действия в Mini App.

## Разработка рабочего кабинета

В отдельной feature-ветке / PR подготавливаются:
- Director Mini App и серверная проверка Telegram Web App `initData`;
- единая полная роль директора и заместителя директора без системы помощников и наблюдателей;
- D1-таблицы для четырёх фотографий, версий композиток и журнала действий;
- архитектура третьего бота-секретаря с командой `/comp Фамилия`;
- CI с TypeScript typecheck и проверкой D1-миграций.

Эти компоненты не считаются включёнными в production, пока соответствующие изменения не объединены в `main` и деплой не завершился успешно.

## Локальная разработка

Требуется Node.js 20+.

1. Установить зависимости: `npm install`.
2. Скопировать `.dev.vars.example` в `.dev.vars` и заполнить локальные значения. Не добавлять реальные секреты в Git.
3. Применить миграции к локальной D1: `npm run db:migrate:local`.
4. Запустить: `npm run dev`.
5. Проверить типы: `npm run typecheck`.

## Production secrets

Секреты Worker управляются через GitHub Actions / Cloudflare. Текущий workflow использует:
- `MODEL_BOT_TOKEN`
- `DIRECTOR_BOT_TOKEN`
- `MODEL_WEBHOOK_SECRET`
- `DIRECTOR_WEBHOOK_SECRET`
- `OWNER_TELEGRAM_ID`
- `DIRECTOR_TELEGRAM_ID`

Токены и секреты нельзя публиковать в репозитории или переписке.

## Принципы доступа

- Модель не управляет фотографиями и не получает композитку.
- Директор управляет анкетами, фотографиями и рабочими карточками.
- Директор и заместитель директора имеют одинаковый полный доступ; отдельные роли помощников и наблюдателей не используются.
- Telegram ID — основной идентификатор пользователя; username не используется как идентификатор доступа.
- Mini App проверяет подпись и срок действия Telegram `initData` на сервере.
