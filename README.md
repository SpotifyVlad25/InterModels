# InterModels

Закрытая система модельного агентства: Telegram-бот модели, Telegram-бот директора и общая база данных Cloudflare D1.

## Текущий этап

Начальный каркас проекта содержит:
- отдельные webhook-маршруты для Model и Director;
- закрытую регистрацию модели по ФИО или собственному контакту Telegram;
- поиск анкеты в общей базе;
- уведомление директора и ручное одобрение/отклонение;
- привязку Telegram User ID только после одобрения;
- таблицу модельных параметров для следующего этапа.

**Важно:** Cloudflare D1, секреты, Telegram webhooks и реальные анкеты пока не настроены. Боты не запущены и не принимают заявки до завершения настройки.

## Локальная разработка

Требуется Node.js 20+.

1. Установить зависимости: `npm install`.
2. Скопировать `.dev.vars.example` в `.dev.vars` и заполнить локальные значения. Не добавлять реальные секреты в Git.
3. Применить миграции к локальной D1: `npm run db:migrate:local`.
4. Запустить: `npm run dev`.

## Cloudflare

1. Создать D1 database с именем `intermodels-db`.
2. Вставить выданный Cloudflare database ID в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`.
3. Применить миграции: `npm run db:migrate:remote`.
4. Добавить Worker Secrets:
   - `MODEL_BOT_TOKEN`
   - `DIRECTOR_BOT_TOKEN`
   - `DIRECTOR_TELEGRAM_ID`
   - `MODEL_WEBHOOK_SECRET`
   - `DIRECTOR_WEBHOOK_SECRET`
5. Развернуть Worker: `npm run deploy`.
6. Настроить Telegram webhooks:
   - `https://<worker-domain>/webhook/model`
   - `https://<worker-domain>/webhook/director`

Для каждого webhook передаётся соответствующий `secret_token`, совпадающий с Worker Secret.

## База моделей

Анкеты должны быть внесены в таблицу `models` до регистрации. Публичного добавления анкет в этой версии нет — это внутренняя операция директора/администратора.

## Безопасность и ограничения MVP

- Не публиковать bot token, webhook secret или другие секреты в GitHub и переписке.
- Доступ к анкете выдаётся только после ручного одобрения директора.
- Имя анкеты, телефон, Telegram ID, статус и фотографии не редактируются моделью через этот MVP.
- Модельные параметры хранятся отдельно в `model_profiles`; интерфейс их редактирования будет добавлен следующим этапом.
- Дубликаты анкет передаются директору на ручной выбор.
- Telegram username не используется как постоянный идентификатор; используется Telegram User ID.
